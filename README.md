## 功能
- 📷 扫码入库/出库（手机摄像头）
- 💰 营业额统计（日/周/月报表）
- 📦 库存管理（低库存预警）
- 👥 客户管理（消费历史）
- 🏷️ 预设分类：上衣/夏季/春秋/冬季/裤子/配饰
- ☁️ 多人云端实时同步
